# Definition of Ready

An issue is ready for implementation when:

- lifecycle phase is identified
- purpose is clear
- scope is clear
- out-of-scope items are clear
- acceptance criteria are testable
- technical constraints are documented
- review viewpoints are identified when specialized review is needed
- test viewpoints are identified for high-risk behavior
- dependencies are complete or explicitly non-blocking
- write scope is defined
- verification method is defined
- owner and executor are assigned
- large issues are split before implementation

AI tools must not start implementation for issues that do not meet this
definition unless the task is specifically to clarify or decompose the issue.
