# Design

First record marker selects risk exactly as existing Project aggregation. Existing Diagnostic serialization is reused. Severity case follows reports; state case warns because closed-state behavior is case-sensitive. No config or external surface added.

Review viewpoints: compatibility, deterministic output, configuration boundaries, failure behavior, no unintended writes. Test viewpoints: valid/default inputs, malformed inputs, stale state, preserved bytes and existing regression suites.
