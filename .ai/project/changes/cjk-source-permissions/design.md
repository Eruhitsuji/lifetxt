no redirects, no cache replacement, no downloaded-code execution, no automatic
network during normal build/Worker, no input/user-data processing. Offline
probe complexity O(fixed data plus one source archive) and <=1MB per fetched
file; no impact on interactive checker. Output contains no host filesystem paths.

explicit fetch no-overwrite/bounds, actual fixed-cache verification, notice/source

Rollback: human-reviewed revert of this PR. No runtime, deployed product,
