# Quick Capture 練習室

lifetxt のソースを取得し、リポジトリのルートでターミナルを開きます。Python 3.10 以上が必要です。追加パッケージのインストールは不要です。

- Windows: `py -3 contrib/quick-capture-practice/start.py`
- macOS / Linux: `python3 contrib/quick-capture-practice/start.py`

ブラウザーが開かない場合は、ターミナルに表示される `http://127.0.0.1:…/` を開いてください。終了はターミナルで Ctrl+C です。

「出題範囲」で Quick 省略記法（14問）、正式な life.txt 形式（20問）、todo.txt 形式（16問）を切り替え、問題を選択します。「入力例を見る」で各問の入力例を確認できます。入力欄の下には、形式ごとの解説があります。

Quick は「記録」で確定します。todo.txt は「プレビュー」で変換結果を確認し、「確認して記録」で確定します。正誤の判定と記録は練習ページ内で行います。「自由入力」では課題なしで変換を試せます。再読み込みで練習履歴と進捗が消えます。

入力はこのPC上のループバック通信だけで処理されます。相対日は起動したPCのローカル日付を基準に解決します。Web UI の共有解析器を使用しています。練習室ではワークスペース設定、他レコードとの参照整合性、実ファイル書き込み時の自動ID採番は適用しません。

起動スクリプトは、同じソースツリー内にある `lifetxt.quick_input.resolve_quick_input` を使用します。
