## Scoping note

#273 (risk classification and a pre-mutation review/approval gate for
high-impact updates) is a separate, not-yet-implemented follow-up issue.
`server-update --yes` today runs its full flow unconditionally once the
target commit is resolved -- there is no risk-based stop point. This is
intentional scope discipline (per `TASK_DECOMPOSITION.md`'s pre-implementation
checks): #260 was decomposed into #270/#271/#272/#273 specifically so the
core flow and the review gate could be reviewed and merged independently,
rather than requiring one large PR.
