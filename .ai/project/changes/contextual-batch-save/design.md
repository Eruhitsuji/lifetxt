# Contextual batch save

POST /api/items/batch remains legacy when context_token is absent. Presence opts into the guard; null, wrong type or malformed v1 token returns400 CONTEXT_TOKEN_INVALID with saved:0. expected_source_revision (or legacy alias expected_revision) remains required (428 REVISION_REQUIRED), alongside existing If-Match and clock/auth middleware. The UI change lives in #1189.

Reuse review_batch, which copies effective config, validates proposed text through Core, captures bounded exact-byte context and validates combined workspace+batch using synthetic labels. It returns private parsed items/context separately from the public Preview. Compare the recomputed exact-input token before evaluating diagnostics. Mismatch =>409 CONTEXT_CHANGED, reason=context_or_input_changed, repreview_required:true, saved:0. Unavailable context =>same409 with safe acquisition reason; no current/expected token echo. Stateless tokens cannot attribute a hash mismatch to a particular source. Unsupported input Format/count overflow remain422 and byte overflow413 before context acquisition. Unchanged complete review errors yield422 DUPLICATE_ID or VALIDATION_ERROR with safe diagnostics. Warnings stay warnings.

Middleware auth/clock/If-Match/unsupported-writable guards run first and preserve their error precedence. Body revision must match captured writable revision, then mutation.write_text(expected_hash=revision) applies one entire batch. No fresh health check is trusted as Preview. Old tokens can be computed by clients; they detect changes, not authentication or proof a human reviewed.

No re-open of sources for semantic validation: use captured texts and batch records. Memory/time remain bounded by existing snapshot limits and Core graph behavior. No new locks. Final destination CAS prevents writable races; a nonwritable source can change immediately after the final scan and before write. Deterministic race injection retains this explicit limitation, including possible late ID collision. External config edits require server restart; startup-expanded membership change requires re-resolution. Revert PR for rollback; no migration.

Self-review found existing generic middleware conflicts echo a private path. For context_token-present batch requests only, normalize middleware CAS/precondition/unsupported-Format failures to their existing status/code plus saved:0, stripping private fields. Legacy conflict payload stays intact; no generic header/audit redesign.

Final CAS also requires the active If-Match transaction revision to equal the captured writable revision; a later body snapshot cannot replace the original header precondition. Deterministic restored-context race verifies this independently of token mismatch. Saved items get the actual writable source, not the synthetic batch diagnostic label.
