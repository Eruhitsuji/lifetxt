This is the active roadmap after the 2026-07-25 delegated-mutation, remote directory/package attachment, subprocess fault-matrix, verified-backup restoration, operator-authorization, remote-write clock-contract, development-ticket-core, shared ticket/project-report, and cross-surface ticket/project integration batches. The safety batch adds a restart-safe delegated-process proposal format that edits only a private temporary copy, validates life.txt output, persists exact source/proposal/content/diff revisions, supports inspect/apply/reject after process restart, rejects proposal tampering, and preserves one-winner/one-conflict semantics; exposes directory-reference, deterministic package, reconcile, open-plan, bounded chunk-read, package-manifest inspection, and transaction-status contracts through Web and MCP with exact item/attachment/metadata revisions, confined server-side package sources, stable retry IDs, duplicate-ID recovery reports, no remote opener execution, and capability discovery; makes an offset-aware client timestamp optionally mandatory for every writable Web and MCP operation while leaving parser-only endpoints usable; expands the subprocess `os._exit` drill from two boundaries to a deterministic 16-boundary matrix with automatic pre-journal orphan cleanup, normal stale-lock recovery, resume/compensation, and repeated terminal recovery; adds integrity-verified restore from an immutable backup through a separate working copy plus optional operator allow-list enforcement; publishes seven safety schemas and raises the Draft 2020-12 bundle from 45 to 52 documents; and documents the full workflow in English and Japanese. The ticket batches add the `record:ticket` model and local management operations plus a versioned, read-only `ticket-project-report-v1` aggregation contract with deterministic summary, board, attention, dependency, due-date, stale, assignment, severity, and estimate/elapsed metrics; register the report through `schema_extensions_v16`; integrate the exact same report into the main `ticket`/`project` CLI trees, Project Hub, Portfolio, and read-only MCP; normalize configured project aliases before aggregation; derive terminal statuses, high severities, and stale windows from effective ticketing configuration while retaining explicit overrides; publish the operations and effective settings through capability discovery; add exact source-file SHA-256 discovery and optional/required optimistic-concurrency checks for `ticket edit|assign|close|reopen|link|unlink`, with shared sidecar locking, in-lock ticket/relation transforms, stale-write refusal, CAS-aware dry runs, per-command and configuration enforcement, and capability discovery while keeping remote ticket writes disabled; add a typed `ticketing.custom_fields` registry with string/integer/number/boolean/date/datetime/duration/enum validation, defaults, required/repeatable rules, enum/bounds/pattern constraints, tracker/project applicability, filter/search/privacy/role metadata, local CLI discovery/create/filter/show integration, in-lock exact-revision validation, capability discovery, and `ticket-custom-field-registry-v1`; add versioned workflow, append-only event/time, and version/sprint planning contracts with exact-revision same-file compound mutation, local CLI and read-only MCP/capability integration, and seven new schemas; add exact multi-file ticket revision sets, journal-backed split-source transition/comment/change/assignment/watch/time/planning commits, deterministic resume/compensate/abandon recovery, and previewed all-or-none bulk transition/change/assignment/planning; add the deny-by-default Remote Safe Mode with role/scope/project/group/visibility filtering, Bearer and trusted-proxy authentication, HTTPS/revision admission, bounded audit output, dependency-free profiles/export/TUI, and six schemas; and add Remote protocol v2 with opaque browser sessions, CSRF/origin protection, capability revision negotiation, a shared filtered read backend, dependency-free resource/diagnostic commands, and five additional schemas, raising the generated/public Draft 2020-12 bundle to 75 documents. Completed sub-items are removed from the roadmap rather than repeated. Remaining P0 work is limited to real observe-to-required deployment evidence, adapter-specific adoption of the delegated proposal contract, real remote-client/restart/divergence evidence, physical power/storage/platform failure evidence, encrypted and role-controlled evidence operations, shared timezone fixtures, and real terminal/browser/SMTP verification. Remaining ticket work focuses on authenticated and cross-surface workflow enforcement, extending the implemented multi-file journal contract to watcher delivery/timer/relation/attachment/archive side stores, advanced release/sprint metrics, custom-field privacy, report revision metadata, and Web/TUI/saved-view/remote/command-center adoption rather than rebuilding the implemented workflow, history, time, planning, revision-set, recovery, and bulk foundations. Remaining Remote work focuses on real browser/TLS/proxy and multi-worker evidence, durable session/audit policy, complete read-surface adoption through a shared local/remote backend, compatibility/performance contracts, and permission/history/privacy/clock/idempotency/recovery-complete mutation routing. The CLI-only deterministic two-counter runtime remains planned work and is not claimed as implemented.
