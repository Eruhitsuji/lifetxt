# オプション依存関係の互換性

安定版の依存関係ポリシーは `pyproject.toml` のメタデータを正とします。
コアパッケージは追加の実行時依存関係を持たず、Web と TUI はそれぞれの
extra で明示的にインストールします。

## 安定した範囲

- `web`: `fastapi>=0.95,<1.0` と `uvicorn[standard]>=0.22,<1.0`
- `tui`: `textual>=0.24,<1.0` と `watchdog>=3,<7`

CI とリリースポリシーのメタデータテストは、これらの範囲とコアの依存関係なし
という境界を検証します。範囲を変更する場合は、互換性環境とリリース証跡を
同じ変更で更新します。

## インストール

```console
python -m pip install ".[web]"
python -m pip install ".[tui]"
```

開発用の監査・テストツールは実行時依存関係ではありません。
