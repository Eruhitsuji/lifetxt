# 安定版互換性ポリシー

このポリシーは、安定版として約束する公開契約と、実験的または保留中の範囲を
分けます。リリースノート、アップグレード手順、リリース候補のレビューは、
このポリシーと `.ai/project/STABLE_RELEASE.yml` のサポートマトリクスを
一緒に参照します。

## 安定版の約束

- CLI の安定したコマンド、終了コード、診断 JSON の公開フィールド
- `life.txt` の Format 1.0 と正規化の契約
- Web/MCP/Remote のうち、サポートマトリクスで stable と明記された読み取り面
- 安全な書き込みについて明示された precondition、競合、復旧の結果

安定したフィールドや動作を削除・変更する場合は、先に非推奨化、移行方法、
リリースノートを用意します。未知の JSON フィールドは将来追加され得るため、
クライアントはそれらを無視します。

## 境界

実験的な書き込み面、未検証のブラウザ統合、SMTP 配送、外部プロバイダーの
副作用、サポートマトリクスで保留とされた範囲は、安定版の約束に含めません。
互換性を安全に維持できない変更は、例外として扱い、影響と移行手順を記録した
人手承認を必要とします。
